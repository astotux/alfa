# Backend

### Создать и заполнить .env по примеру .env.example

### Скачиваем uv
```cmd
pip install uv
```

### Далее
```cmd
uv sync
```


### Запуск
```bash
uv run src/main.py
```

# Frontend

### Скачиваем зависимости
```bash
npm i
```

### Запуск проекта в dev
```bash
npm run dev
```

### build проекта
```bash
npm run build
```
