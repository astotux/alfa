# Backend

### Сделать виртуальное окружение
```cmd
python -m venv .venv
```

### Активация виртуальное окружение
```cmd
.venv\Scripts\activate
```

### Установить зависимости 
```bash
pip install -r requirements.txt
```

### Запуск в dev 
```bash
pip install -r requirements.txt
```

### Запуск
```bash
python main.py
```
